# Casework — pre-case working material

This folder holds source material for cases that **do not exist yet**: AI
deep-research briefs, audit reports, and other seed documents supplied by
the founder while a case is being scoped and built.

It is committed to this repository **only because the repository is
private** (decided 2026-08-25, amending the same-day local-only rule) so
that cloud agents can work on new cases from it. If the repository ever
goes public, this folder must be removed from the tree — and from history —
first.

## What this material is, and is not

- These documents are **discovery aids**, mostly AI-generated deep-research
  reports. They are starting maps, not sources.
- **Nothing in this folder may ever be cited** as a Source or Evidence
  record. Every citation they contain must be independently retrieved and
  verified against the primary source before it enters `content/`
  (`docs/CONTENT_POLICY.md`).
- Nothing here is imported wholesale. A case enters `content/` only when it
  is scaffolded record by record, each record carrying its own provenance
  and verification label — the same way Case #9 (TIK-001) was built from
  briefs like these.
- The two briefs per case come from different AI vendors; treat their
  overlapping citations as one dependent trail until verified, never as
  mutual corroboration.
